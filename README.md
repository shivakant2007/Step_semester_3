# STEP Semester 3 — Java Coursework

## Overview
This repository contains the complete Java coursework for STEP Semester 3, organized by session and assignment.

## Branch Structure

- **`main`** — Documentation only (this README). No Java source code.
- **`dev`** — Empty Java project skeleton structure. No solved code.
- **`feature/week3`** — All implemented Java coursework (20 programs).

## Coursework Contents

### Day 1 — Live Coding / Practice Problems (5 programs)
1. **RockPaperScissors** — Randomized Rock-Paper-Scissors game with N rounds, win/loss/draw tracking, and win percentage.
2. **PalindromeChecker** — Three independent approaches: iterative, recursive, and character-array reversal.
3. **BmiCalculator** — Team BMI calculator with classification and wellness report.
4. **FirstNonRepeatingCharacter** — Finds the first non-repeating character using frequency counting.
5. **ReverseCustomerName** — Reverses a customer name while preserving the original.

### Week 1 — Assignment Problems (5 programs)
1. **DuplicateSeatChecker** — Checks for duplicate seat numbers using arrays and loops only.
2. **TypingAccuracyChecker** — Character-by-character typing accuracy comparison with mismatch reporting.
3. **TrafficSignalStreakAnalyzer** — Finds the longest consecutive streak in a signal string.
4. **WarehouseInventoryBalancer** — Compares two warehouse sections and reports balance status.
5. **MovieReviewWordLengthProfiler** — Classifies words in a review into Short/Medium/Long categories.

### Day 2 — Live Coding / Practice Problems (5 programs)
1. **VowelConsonantCounter** — Counts vowels and consonants case-insensitively.
2. **CsvStudentRecordParser** — Parses CSV student records using `split(",")`.
3. **FileExtensionValidator** — Validates file extensions using `lastIndexOf` and `substring`.
4. **MaskedPhoneNumberFormatter** — Masks a 10-digit phone number.
5. **BankTransactionReferenceValidator** — Validates and formats bank transaction references.

### Week 2 — Assignment Problems (5 programs)
1. **AtmPinLengthValidator** — Validates ATM PIN length (must be exactly 4 digits).
2. **WordReversalEncoder** — Reverses each word in a sentence while preserving word order.
3. **ProductInventoryCsvParser** — Parses product inventory CSV records.
4. **LibraryIsbnNormalizer** — Validates and normalizes library ISBN codes.
5. **StopWordFrequencyReport** — Filtered word frequency report excluding stop words.
